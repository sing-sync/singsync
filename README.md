# SingSync プレイヤー（配布用リポジトリ）

授業でつくったカラオケPVを、生徒のiPadにQRコードで配るための公開フォルダです。
くわしい手順は **はじめかた.html** をダブルクリックしてご覧ください（印刷もできます）。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | プレイヤー本体（SingSyncそのもの。`?song=` 付きで開くと生徒用プレイヤーになります） |
| `songs/` | 曲パック置き場。SingSyncの⑤書き出し「📲 iPadに配る」で作った `〇〇.pack.json` をここに入れます |
| `songs/a-brand-new-day.pack.json` | 動作確認用のサンプル曲 |
| `はじめかた.html` | 初期設定〜日常運用の手順書 |
| `.nojekyll` | GitHub Pages用のおまじない（消さないでください） |

## ふだんの運用（曲を配るとき）

1. SingSync ⑤書き出し → 「📲 iPadに配る」 → **📦 曲パックを書き出す**
2. できた `〇〇.pack.json` を `songs/` に入れる
3. GitHub Desktop で **Commit to main → Push origin**
4. 2〜3分待つ → アプリに出ているQRコードで開けるか確認 → 配布

生徒が開くURLの形:
`https://組織名.github.io/リポジトリ名/?song=songs/〇〇.pack.json`

※ URLに個人アカウント名が出ないよう、このリポジトリは **Organization（組織）の下** に置く方針です。GitHub Desktop はふだんのアカウントのままで大丈夫です（サインアウト不要）。

## アプリ本体を更新するとき

新しい `SingSync.html` をコピー → 名前を `index.html` に変えて、ここの `index.html` と入れ替え → Commit → Push。
配布済みの曲パックはそのままで、全曲に新機能が届きます。

## 注意

- ここは**公開リポジトリ**です。URLを知っていれば誰でも音源・歌詞にアクセスできます。Sunoで自作した曲だけを置き、ファイル名・曲名に学校名や生徒名を入れないでください。
- 曲を差し替えたのに古いまま見えるときは、iPad側でページを再読み込みしてください。
