♪ SingSync プレイヤー はじめかた

つくったカラオケPVを、生徒のiPadにQRコードだけで配れるようにする手順書です。
最初の設定はぜんぶで30分ほど。いちど済ませれば、あとは曲1つにつき5分です。

じぶんのMac GitHub（無料） 生徒のiPad ┌──────────────┐ アップロード ┌──────────────┐ QRを読む ┌──────────────┐ │ SingSyncで │ ───────────▶ │ 公開ページ │ ─────────▶ │ ブラウザで │ │ 曲パックを書き出す │ (GitHub Desktop) │ ＝プレイヤー置き場 │ (カメラ) │ うたう・穴あき練習 │ └──────────────┘ └──────────────┘ └──────────────┘
さきに知っておくこと：GitHubの公開ページは「URLを知っていれば誰でも見られる」場所です（検索にはほぼ載りません）。音源と歌詞がインターネットに置かれることになるので、Sunoで自作した曲だけを使い、曲名やファイル名に学校名・生徒の名前を入れないでください。

0. 用意するもの確認だけ

  • デスクトップの singsync-site フォルダ（この手順書が入っているフォルダ。公開する中身一式です）
  • いまお使いのGitHubアカウント（GitHub Desktopでサインイン済みのもの。新しく作る必要も、サインアウトする必要もありません）
  • GitHub Desktop アプリ（ふだんお使いのもので大丈夫です）

1. 公開用の名前（Organization）をつくる約5分

生徒に配るURLには、置き場所の名前がそのまま出ます。ふだんのアカウント名を出したくないので、公開用の名前を1つ「組織（Organization）」として無料でつくります。いまのアカウントにぶら下がる形なので、アカウントを増やす必要も、GitHub Desktopをサインアウトする必要もありません。

  1. ブラウザで github.com にログインし、右上のアイコン → Your organizations → New organization
  2. プランは Free（無料・0円）を選ぶ
  3. Organization name に公開用の名前を入れる（例 singsync-eigo）
  4. Contact email は、いまお使いのメールアドレスのままでOK
  5. 「This organization belongs to」は My personal account（個人用）を選ぶ
  6. Next → 仲間を誘う画面が出たら、何も入れずにスキップ（ひとりで使います）
名前の決め方：半角の英小文字・数字・ハイフンだけが使えます。GitHub全体で早い者勝ちなので、すでに使われている名前は赤い字ではじかれます（別の名前にすれば大丈夫です）。学校名・本名・生徒に関わる言葉は入れないでください。この名前がそのまま https://この名前.github.io/… になります。

画面は英語ですが、この手順書のとおりに進めば大丈夫です。以降この手順書では、ここで決めた名前を 「組織名」と書きます。

2. 公開リポジトリ（GitHub上のフォルダ）をつくる約5分

  1. GitHubにログインした状態で、右上の「＋」→ New repository
  2. Owner（左のプルダウン）を、手順1で決めた「組織名」に切り替える ← ここが最重要
  3. Repository name に singsync と入力（別の名前でもOK。URLの一部になります）
  4. 公開設定は必ず Public を選ぶ
  5. ほかは何も変えずに Create repository
ここでつまずきがち①：Owner が自分のアカウント名のままだと、せっかく組織を作ったのにURLに自分のIDが出てしまいます。作成ボタンを押す前に、入力欄の左が 組織名 / になっているか指差し確認を。（まちがえても、あとから Settings のいちばん下にある Transfer ownership で組織に引っ越せます。）
ここでつまずきがち②：うっかり Private（非公開）にすると、無料プランでは公開ページ（Pages）が使えません。いちばん多い事故です。Public になっているか指差し確認を。

3. GitHub Desktopで自分のMacにつなぐ約5分

  1. GitHub Desktop を開く（いまのアカウントのままでOK。サインアウトはしないでください）
  2. File → Clone Repository → 一覧から 組織名/singsync を選んで Clone（保存先はそのままでOK）

これで「GitHub上のフォルダ」と「Macの中のフォルダ」がつながりました。一覧に出てこないときは、URL のタブに 組織名/singsync と直接打ちこんでも入れます。

任意（気になる方だけ）：アップロードの記録には、ふだんお使いのお名前とメールアドレスが残ります。そこも隠したいときは、GitHub Desktop の Repository → Repository settings → Git config で Use my local Git config を選び、名前を公開用の名前に、メールを 〇〇@users.noreply.github.com（GitHubの Settings → Emails に書いてある非公開用のアドレス）に変えてください。このリポジトリだけの設定なので、ほかの作業には影響しません。

4. 公開する中身を入れて、アップロードする約5分

  1. Finderでデスクトップの singsync-site を開く
  2. 隠れているファイルも見えるように、⌘（コマンド）+ Shift + .（ピリオド） を押す（.nojekyll という薄字のファイルが出てきます。地味ですが公開に必要なファイルです）
  3. ⌘ + A で中身を全部選択 → ⌘ + C でコピー
  4. 貼り付け先を開く：GitHub Desktopの上のメニューから Repository → Show in Finder を選ぶ。手順3でクローンした singsync フォルダが一発で開きます（フォルダを自分で探し回らなくて大丈夫です）
  5. 開いたFinderのウィンドウで ⌘ + V を押して貼り付ける
  6. GitHub Desktopに戻ると、左に変更一覧が出ています。左下の欄に「はじめての公開」などと書いて Commit to main を押す（＝荷造り）
  7. 上に出る Push origin を押す（＝発送。ここまでやって完了です）
ここでつまずきがち①：singsync-site というフォルダごと貼り付けると失敗します（ページが404になります）。中身だけを貼り付けて、index.html がリポジトリのいちばん上の階層に来るようにしてください。
正しい形: まちがい: singsync/ singsync/ ├─ index.html ← 直下にある └─ singsync-site/ ├─ songs/ ├─ index.html ← 1段深い＝404 └─ はじめかた.html └─ songs/
ここでつまずきがち②：.nojekyll は名前が「.」で始まるため、Finderの初期設定では見えません。上の手順どおり ⌘+Shift+. で表示してからコピーしないと、うっかり入れ忘れます（もう一度 ⌘+Shift+. を押すと元の表示に戻せます。入れ忘れに気づいたら、あとから同じ手順でこのファイルだけ追加すればOKです）。

5. 公開スイッチ（Pages）を入れる約5分

  1. ブラウザでGitHubの singsync リポジトリを開き、上の Settings → 左の Pages
  2. Source が Deploy from a branch になっているのを確認
  3. Branch で main と /(root) を選んで Save
  4. 2〜3分待ってからこのページを再読み込みすると、上部に https://組織名.github.io/singsync/ というURLが出ます。これが配布先URLです
ここでつまずきがち：Saveのあと、すぐ開くと404が出ます。失敗ではありません。設定をいじり直さず、お茶を一杯飲んでからもう一度開いてください（初回は最大10分ほどかかることがあります）。

6. 動作確認（サンプル曲入り）約2分

お手元のスマホのカメラで確認するのがおすすめです。ブラウザで次のURLを開いてください：

https://組織名.github.io/singsync/?song=songs/a-brand-new-day.pack.json

タイトル画面 →「▶ はじめる」→ 歌詞シートが出て、行をタップすると歌が流れれば成功です 🎉
確認がすんだら、SingSyncの⑤書き出しにある「📲 iPadに配る」の配布先URL欄に https://組織名.github.io/singsync/ を入れておきましょう（QRコードが作れるようになります）。

7. ふだんの運用（曲を配るとき）曲1つ 約5分

📌 これだけ見ればOK（切りとって机に貼れます）

  1. SingSyncで曲を開く → ⑤書き出し → 「📲 iPadに配る」→ 📦 曲パックを書き出す
  2. ダウンロードされた 〇〇.pack.json を、Macの singsync フォルダの songs に入れる
  3. GitHub Desktop → Commit to main → Push origin
  4. 2〜3分待つ → SingSyncの画面に出ているQRコードを自分のスマホで読んで開けるか確認
  5. 「🖨 配布カードを印刷」して黒板に貼る（またはQRを大きく映す）

・同じファイル名で書き出す＝曲の差し替え（生徒側は再読み込みで新しくなります）
・穴あき・注釈・よみあげ・ペンは、仕込んだ内容ごと自動で生徒版に入ります

8. アプリ本体を新しくしたとき

SingSyncに新機能が増えたら、プレイヤーも差し替えると配布済みの全曲に新機能が届きます。

  1. 新しい SingSync.html をコピーして、名前を index.html に変える
  2. Macの singsync フォルダの index.html と入れ替える
  3. GitHub Desktopで Commit to main → Push origin（曲パックはそのままでOK）

9. こまったとき Q&A

「曲が見つかりません」と出る ① Pushしてから2〜3分待ちましたか？ ② ファイル名は songs の中の名前と大文字小文字まで一致していますか？ ③ パックは songs フォルダの中にありますか？

組織のものが出ない		 GitHub Desktopの一覧が古いままです。いちどアプリを閉じて開き直すか、URL タブに 組織名/singsync と直接打ちこんでください。サインアウトは不要です。
曲を差し替えたのに古いまま iPad側でページを再読み込み（アドレスバーの更新ボタン）。それでも古いときは数分おいてもう一度。

iPadで音が出ない 「▶ はじめる」をタップしてから行をタップ。本体の音量と消音スイッチ（マナーモード）も確認。
背景の動画が出ない 仕様です。曲パックには容量の都合で動画背景は入りません（写真とグラデーションで表示されます）。
